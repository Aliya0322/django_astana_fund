## Описание проекта

**Astana Fund** — это современный веб-сайт для Фонда содействия развитию дружбы народов и национальных культур "АСТАНА". Сайт предоставляет полную информацию о деятельности фонда, включая мероприятия, проекты, публикации в СМИ и культурные материалы.

### Основные функции:

- **Управление мероприятиями** - отображение предстоящих и прошедших событий с детальной информацией
- **СМИ о нас** - публикации и репортажи о деятельности фонда
- **Проекты** - информация о текущих, завершенных и постоянных проектах
- **Интересное** - мультимедийный контент (видео, музыка, статьи)
- **Обратная связь** - форма для связи с фондом
- **Глобальный поиск** - поиск по всему контенту сайта
- **Адаптивный дизайн** - оптимизация для всех устройств

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)
- Git

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/django_astana_fund.git
cd django_astana_fund
```

### 2. Создание виртуального окружения

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (macOS/Linux)
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта:

```env
# Django настройки
DJANGO_SECRET_KEY=your-secret-key-here
DJANGO_DEBUG=True

# База данных (для разработки используется SQLite)
DB_ENGINE=sqlite3

# Email настройки (опционально)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
DEFAULT_FROM_EMAIL=your-email@gmail.com
CONTACT_EMAIL=contact@yourdomain.com
```

### 5. Выполнение миграций

```bash
python manage.py migrate
```

### 6. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 7. Сбор статических файлов

```bash
python manage.py collectstatic
```

### 8. Запуск сервера разработки

```bash
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

## Развертывание

### Vercel (Serverless)

Проект готов к развертыванию на Vercel:

```bash
# Установка Vercel CLI
npm i -g vercel

# Деплой
vercel
```

### PythonAnywhere

Для развертывания на PythonAnywhere используйте файл `settings_production.py`:

1. Создайте базу данных MySQL
2. Настройте переменные окружения
3. Выполните миграции
4. Настройте статические файлы

Подробная инструкция в файле `DEPLOYMENT_PYTHONANYWHERE.md`

### Docker (опционально)

```bash
# Сборка образа
docker build -t astana-fund .

# Запуск контейнера
docker run -p 8000:8000 astana-fund
```
